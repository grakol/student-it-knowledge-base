## Najważniejsze polecenia

| Polecenie | Przykład użycia | Opis |
| :--- | :--- | :--- |
| `dotnet --version` | `dotnet --version` | Sprawdza wersję aktualnie używanego zestawu .NET SDK. |
| `dotnet --list-sdks` | `dotnet --list-sdks` | Wyświetla listę wszystkich zainstalowanych wersji SDK na komputerze. |
| `dotnet new list` | `dotnet new list` | Wyświetla dostępne szablony projektów (np. konsolowy, webowy). |
| `dotnet new console` | `dotnet new console` | Tworzy nową aplikację konsolową w bieżącym katalogu. |
| `dotnet new console -n` | `dotnet new console -n MyApp` | Tworzy nową aplikację konsolową w osobnym folderze `MyApp`. |
| `dotnet restore` | `dotnet restore` | Pobiera pakiety i zależności wymagane przez projekt. |
| `dotnet build` | `dotnet build` | Kompiluje projekt i sprawdza, czy nie ma błędów w kodzie. |
| `dotnet run` | `dotnet run --project MyApp` | Kompiluje i uruchamia wskazaną aplikację. |
| `dotnet clean` | `dotnet clean` | Usuwa pliki wygenerowane podczas poprzedniej kompilacji. |
